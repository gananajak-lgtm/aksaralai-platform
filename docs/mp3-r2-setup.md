# อักษราลัย — เปิดระบบ MP3 ฟังเบื้องหลัง

โค้ดตัวเล่นและ API อัปโหลดผ่าน GitHub Actions แล้ว แต่ระบบจะยังไม่รับไฟล์จนกว่าจะเชื่อม **Cloudflare R2** จริง

## เปิด R2 ครั้งแรก (เจ้าของบัญชีทำเอง)

1. เปิด Cloudflare Dashboard ของบัญชีที่ใช้งาน `aksaralai-platform`.
2. ไปที่ **R2 Object Storage** และเปิดใช้งานตามเงื่อนไขบัญชี จากนั้นสร้างบัคเก็ตชื่อ **`aksaralai-audio`**.
3. แจ้งผู้พัฒนาเมื่อสร้างบัคเก็ตสำเร็จ เพื่อเพิ่ม binding ใน `wrangler.toml` แล้วรันระบบ Deploy/ทดสอบต่อ:

   ```toml
   [[r2_buckets]]
   binding = "AUDIO"
   bucket_name = "aksaralai-audio"
   ```

**อย่าตั้ง R2 bucket นี้เป็น Public**. ทุกการดาวน์โหลดควรเข้าผ่าน API ที่ยืนยันเซสชันของสมาชิกก่อน

## วิธีใช้หลังเชื่อม R2

- เข้าสู่ระบบด้วยบัญชีนักเขียน → สตูดิโอ → เลือกเรื่อง → แก้ไขตอนที่บันทึกแล้ว → อัปโหลด MP3.
- รองรับไฟล์นามสกุล `.mp3` ขนาดไม่เกิน 40 MB ต่อหนึ่งตอน; การอัปโหลดใหม่ทับไฟล์เดิมของตอนนั้น.
- สมาชิกที่ล็อกอินอยู่จะเห็นเครื่องเล่น MP3 บนหน้าอ่าน หากตอนนั้นมีไฟล์เสียง.
- ใช้ HTML audio และ Media Session เพื่อรองรับปุ่ม Play/Pause/เลื่อนเวลาใน Android และบันทึกตำแหน่งฟังไว้บนอุปกรณ์เดียวกัน.
- เสียงอ่านสดของ Android ยังอยู่เป็นตัวเลือกเดิม ไม่ต้องลบเนื้อหานิยายหรือย้ายฐานข้อมูล D1.

## ข้อจำกัด

- การเล่นขณะล็อกหน้าจอขึ้นกับ Android, เบราว์เซอร์, นโยบายประหยัดแบตเตอรี่และเครือข่าย ต้องทดสอบกับมือถือจริง.
- ผู้ใช้ต้องเริ่มเล่นไฟล์ MP3 ก่อนล็อกหน้าจอ; การเล่นอัตโนมัติจากแอปโดยไม่ได้กดเล่นอาจถูกเบราว์เซอร์บล็อก.
- ถ้าเชื่อม R2 ไม่สำเร็จ ปุ่มอัปโหลดจะไม่ทำงาน แต่การอ่านนิยายและระบบ TTS เดิมยังทำงานได้.
- ไม่ต้องนำ API token หรือ Cloudflare secret มาแชร์ในแชต.

# อักษราลัย (Aksaralai) 📚

เว็บไซต์ PWA สำหรับอ่านและเขียนนิยายภาษาไทย มีบัญชีนักอ่านและนักเขียนแยกบทบาท ใช้ **Cloudflare Workers + D1** เป็น Backend และฐานข้อมูลส่วนกลาง พร้อม Web Speech API สำหรับอ่านออกเสียงภาษาไทยตามความสามารถของอุปกรณ์

## สิ่งที่มีใน GitHub แล้ว

- `public/index.html` — เว็บแอปแบบ Responsive: สำรวจนิยาย, เข้าสู่ระบบ, ชั้นหนังสือ, หน้าตอน, สตูดิโอนักเขียน และเครื่องเล่นอ่านออกเสียง
- `public/sw.js`, `public/manifest.webmanifest` และไอคอน — โครงสร้าง PWA สำหรับเพิ่มลงหน้าจอหลัก
- `src/index.js` — API สมัครสมาชิก/ล็อกอิน/ล็อกเอาต์, สิทธิ์นักเขียน, CRUD นิยายและตอน, ฉบับร่าง/เผยแพร่, progress, shelves, comments
- `migrations/0001_initial.sql` — ฐานข้อมูล D1 เฉพาะอักษราลัย (ไม่ใช้ฐานข้อมูลพิภพเร้นลับ)
- `test/api.test.js` และ GitHub Actions CI — ชุดทดสอบ API และไวยากรณ์สคริปต์

## ทดลองบนเครื่องด้วย Node.js 22+

```bash
npm install
npm run db:local
npm run dev
npm test
```

เปิด URL ที่ Wrangler แสดงหลังรัน dev ได้เลย ตัวทดสอบใช้ in-memory SQLite mock ให้เสมือน D1; ควรทดสอบ integration บน D1 จริงก่อนใช้งานกับผู้ใช้ภายนอกด้วย

## ติดตั้ง Cloudflare (ยังไม่ได้ deploy)

1. ใช้ **บัญชี Cloudflare ของเจ้าของโปรเจกต์** โดยสร้าง Worker และฐานข้อมูลใหม่ ไม่แตะ resource ของพิภพเร้นลับ
2. `npx wrangler login`
3. `npx wrangler d1 create aksaralai-db`
4. นำ UUID ฐานข้อมูล **ใหม่** มาแทน `PLACEHOLDER_DATABASE_ID` ใน `wrangler.toml`
5. `npm run db:remote`
6. `npm run deploy`
7. เปิด HTTPS workers.dev URL ที่ CLI แสดง แล้วตรวจ PWA และเสียงอ่านบนมือถือจริง

อ่านเอกสาร Cloudflare: https://developers.cloudflare.com/workers/static-assets/ และ https://developers.cloudflare.com/d1/get-started/

**คำเตือน:** อย่าส่ง Cloudflare API token, password หรือค่า secret ให้ผู้อื่นทางแชท และห้ามใช้ database UUID ของพิภพเร้นลับในไฟล์นี้

## ข้อจำกัดก่อนเปิดให้คนทั่วไปสมัคร

แพลตฟอร์มนี้ยังเป็น MVP ไม่มี CAPTCHA/Turnstile, rate limits, email verification, password reset, ระบบรายงานหรือตรวจสอบเนื้อหา, การบล็อกบัญชี, เครื่องมือผู้ดูแล, นโยบายข้อมูลส่วนบุคคล และแผนสำรองข้อมูล โปรดอย่าเปิดรับข้อมูลบัญชีจริงเป็นวงกว้างก่อนปิดช่องว่างเหล่านี้

เสียงอ่านใช้ `speechSynthesis` ของเครื่องผู้ใช้ ไม่ใช่ API เสียง AI; อุปกรณ์บางรุ่นอาจไม่มีเสียงไทยหรือหยุดอ่านเมื่อพักหน้าจอ ระบบยังไม่มีเหรียญหรือการชำระเงินจริง

**สถานะ deployment:** Repo มีโค้ดและไฟล์ตั้งค่าพื้นฐานแล้ว แต่ยังไม่มี D1 UUID, ยังไม่ deploy และยังไม่มี URL สาธารณะ

## ทดลอง OpenAI เสียงภาษาไทย (เฉพาะผู้ดูแล)

ฟีเจอร์นี้เป็นเพียง **ตัวอย่างเสียงสั้น ๆ** (ไม่สร้างนิยายทั้งตอน, ไม่อัปโหลดเข้า R2) เพื่อทดสอบคุณภาพการอ่านภาษาไทยก่อนเปิดใช้จริง โดยจำกัดไม่เกิน 3 คำขอต่อวันตาม UTC และจำกัดสิทธิ์เฉพาะบัญชีนักเขียนที่ตั้งค่าไว้ การเรียกแต่ละครั้งมีค่าใช้จ่าย OpenAI API จริง แม้ยังไม่ได้เผยแพร่เสียงให้ผู้อ่าน

1. เพิ่ม Secret ชื่อ `OPENAI_API_KEY` ใน Cloudflare Worker โดยห้ามใส่ Key ใน GitHub หรือฝั่งหน้าเว็บ
2. เพิ่ม **Secret** ชื่อ `OPENAI_TTS_ADMIN_USERNAME` มีค่าเป็น **username ที่ใช้เข้าสู่ระบบอักษราลัย** ของบัญชีนักเขียนผู้ดูแล (ไม่ใช่ชื่อแสดงหรืออีเมล) หากไม่ตั้งค่า ระบบปิดโดยอัตโนมัติ
3. ก่อน Deploy ให้อัปเดตฐานข้อมูล D1: `npm run db:remote` เพื่อสร้างตาราง `tts_preview_usage`
4. Deploy Worker รุ่นใหม่ แล้วเข้าระบบด้วยบัญชีที่ตรงกับ username ที่กำหนด ไปที่ **สตูดิโอนักเขียน → จัดการนิยาย → แก้ไขตอนที่บันทึกไว้** จะพบปุ่ม **ทดลองสร้างเสียง OpenAI**
5. เปิดฟังตัวอย่างสั้น ๆ และพิจารณาคุณภาพก่อนอนุมัติการพัฒนาระบบสร้างเสียงทั้งตอน

ข้อจำกัด: มีค่าใช้จ่ายตาม API; บัญชี API ต้องมีเครดิต/วงเงินเพียงพอ; คลาวด์ต้องเรียก OpenAI ได้; การลองเสียงยังไม่รับข้อความตามใจผู้ใช้เพื่อลดความเสี่ยงค่าใช้จ่าย; เสียงทดลองไม่ได้แทนที่ MP3 เดิม; ห้ามเปิด endpoint แบบไร้สิทธิ์หรือให้ผู้ใช้งานทั่วไปเรียกโดยตรง. หาก UI ไม่แสดงปุ่ม ให้ตรวจว่าตั้ง Secret ทั้งสองตัวถูกต้องและบัญชีที่ล็อกอินเป็น role=writer และ username ตรงกับค่า `OPENAI_TTS_ADMIN_USERNAME`.

## สตูดิโอ OpenAI: วางข้อความเอง → สร้าง → ดาวน์โหลด MP3

บัญชีผู้ดูแลที่ระบุใน Runtime Secret `OPENAI_TTS_ADMIN_USERNAME` และมี `OPENAI_API_KEY` จะเห็นปุ่ม **🎙️ ใช้ OpenAI** บนแถบนำทางหลังล็อกอินเป็นนักเขียน กดเพื่อเปิดหน้าต่างป๊อปอัป กรอกข้อความของตนเอง เลือกหนึ่งใน 13 เสียง เลือกแนวการอ่านและความเร็ว แล้วกด **สร้างเสียง MP3** เมื่อสำเร็จ สามารถฟังและกด **ดาวน์โหลด MP3 ลงเครื่อง** ใช้ภายนอกได้ทันที การอัปโหลดกลับเข้าอักษราลัยให้ใช้ระบบอัปโหลด MP3 ของตอนนิยายเดิมตามความต้องการ ไม่มีการบันทึก MP3 อัตโนมัติบน R2

**ข้อจำกัดรุ่นแรก:** ข้อความอิสระยาวไม่เกิน 1,500 ตัวอักษรต่อไฟล์ (โมเดลอาจจำกัดโทเค็นต่ำกว่าตัวอักษร); ถ้ายาวกว่านั้นให้แยกสร้างเป็นหลายไฟล์ก่อน รุ่นนี้ยังไม่มีคิวประมวลผลยาวหรือระบบรวมเสียงหลายไฟล์เป็น MP3 เดียว ไม่มีโควตา 3 ครั้งต่อวันสำหรับสตูดิโอ (โควตานั้นยังใช้เฉพาะปุ่มทดลองเสียงตัวอย่างเดิม) และการเรียกทุกครั้งมีค่าใช้จ่าย API จริงตามโมเดลที่ใช้

**ความปลอดภัย/ค่าใช้จ่าย:** Endpoint `POST /api/writer/tts/generate` จำกัดสิทธิ์ด้วยเซสชันบัญชีนักเขียน + username ผู้ดูแลจาก Secret และตรวจ Origin, allowlist เสียง/สไตล์ และความยาวข้อความ ไม่ส่ง API Key ไปฝั่งเบราว์เซอร์ อย่างไรก็ตามรุ่นนี้ยังไม่มีเพดานงบรายวันแยกใน Worker: ต้องควบคุมเครดิต OpenAI แยกต่างหากและไม่แบ่งบัญชีผู้ดูแลให้ผู้อื่น การจำกัดจำนวนตัวอักษรต่อครั้งไม่ได้จำกัดยอดรวมที่สามารถใช้ได้ เมื่อต้องการให้ผู้อื่นใช้หรือสร้างเสียงนิยายทั้งเล่ม ควรเพิ่มคิว/การนับเครดิตและการจำกัดต้นทุนระดับเซิร์ฟเวอร์ก่อน

เสียงที่ได้จาก OpenAI เป็นเสียงสร้างด้วย AI และควรแจ้งให้ผู้รับฟังทราบเมื่อเผยแพร่

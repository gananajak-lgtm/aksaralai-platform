# อักษราลัย (Aksaralai)

แพลตฟอร์มอ่านและเขียนนิยายบนเว็บ พร้อมระบบสมาชิก นักอ่าน นักเขียน และระบบอ่านออกเสียงภาษาไทย (Text-to-Speech)

## สถานะ

- Repository สำหรับพัฒนาแอปอักษราลัยโดยเฉพาะ
- เป้าหมายการเผยแพร่: Progressive Web App (PWA) บน Cloudflare
- แยกจากโปรเจกต์พิภพเร้นลับโดยสิ้นเชิง
- ยัง **ไม่ได้เผยแพร่เว็บไซต์สาธารณะ** และยังไม่เปิดรับข้อมูลผู้ใช้จริง
- ต้นแบบก่อนหน้านี้ใช้ Python + SQLite; ต้องออกแบบ backend/database ให้รองรับ Cloudflare Workers + D1 ก่อนนำขึ้นระบบจริง

## แนวทางพัฒนา

1. นำซอร์สต้นแบบ PWA และ TTS เข้าสู่ repo นี้
2. แปลง API/backend ให้ทำงานกับ Cloudflare Workers และฐานข้อมูล D1 แยกต่างหาก
3. ทดสอบระบบบัญชีผู้ใช้ การแยกสิทธิ์นักเขียน การเผยแพร่ตอน และการอ่านออกเสียง
4. ตั้งค่า secret และ deployment ผ่าน Cloudflare โดยไม่เก็บรหัสผ่านหรือ token ใน Git

> Repo นี้เป็นของเจ้าของบัญชี `gananajak-lgtm`. ใช้บัญชี Cloudflare เดิมได้ แต่ควรแยก Worker และ D1 จากแอปพิภพเร้นลับ
